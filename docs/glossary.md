# Glossary

## Resources and core mechanics

| Term | Meaning |
|---|---|
| **Holy Power / HoPo / HP** | Paladin's secondary resource, capped at **5**. Combo-point-like. Built by generators, consumed by spenders. All three specs use it. Note: "HP" is ambiguous — it can mean Holy Power or health points. |
| **Generator** | An ability that grants Holy Power (e.g. Judgment, Blade of Justice, Holy Shock, Blessed Hammer). |
| **Spender** | An ability that consumes Holy Power (e.g. Final Verdict, Divine Storm, Shield of the Righteous, Word of Glory, Light of Dawn, Hammer of Light). |
| **Overcapping** | Generating Holy Power while already at 5, wasting it. The single most-repeated mistake warning across all three specs. |
| **Mastery** | Each spec has a different Mastery: *Highlord's Judgment* (Ret), *Lightbringer* (Holy), *Divine Bulwark* (Prot). |
| **Active mitigation** | Tank damage reduction you press manually — for Protection this is Shield of the Righteous. |

## Content and role shorthand

| Term | Meaning |
|---|---|
| **M+ / Mythic+** | Timed, scaling 5-player dungeon content. |
| **ST** | Single target. |
| **AoE** | Area of effect / multi-target. |
| **Cleave** | Damage that spills onto nearby targets, usually 2–4 enemies. |
| **Funnel** | Concentrating damage into one priority target while others are alive. |
| **Delves** | Solo/small-group instanced content; short, repeated encounters. |
| **GCD** | Global cooldown — the ~1.5s (haste-reduced) window between ability presses. |
| **ABC** | "Always Be Casting" — never let a GCD go unused. |
| **DR** | Damage reduction (also, separately, "diminishing returns" on secondary stats — context matters). |
| **ilvl** | Item level. |
| **BiS** | Best in slot. |
| **Opener** | The scripted first few seconds of a fight before falling into the priority list. |
| **Priority list** | An ordered list checked top-to-bottom each GCD — *not* a fixed rotation loop. All three Paladin specs use priority lists. |

## Paladin-specific terms

| Term | Meaning |
|---|---|
| **Wings** | Colloquial name for **Avenging Wrath** (from the visual). |
| **Beacon** | Holy's healing-transfer mechanic. Four variants exist: Beacon of Light, Beacon of Faith, Beacon of Virtue, Beacon of the Savior. |
| **Transfer** | The portion of healing done to other targets that is copied onto a Beacon target. |
| **Externals** | Defensive cooldowns cast on *other* players — Blessing of Protection, Blessing of Sacrifice, Blessing of Spellwarding, Lay on Hands. |
| **Aura** | A passive party/raid-wide effect. **Devotion Aura** is the only one used in PvE. |
| **Hero talents** | The third talent tree, introduced in The War Within. Paladin has three: Templar, Herald of the Sun, Lightsmith. Each spec picks from two of them. |
| **Apex talents** | Midnight's new 4-point branch at the base of the spec tree, unlocked at level 81. |
| **Armaments** | Lightsmith's Holy Bulwark / Sacred Weapon pair, which alternate on use. |
| **Dawnlight** | Herald of the Sun's signature DoT/HoT effect. |
| **Empyrean Hammers** | Templar's automatic falling-hammer damage effects. |
